# Nativa Online

Un bosque en ASCII donde la misión no es matar, es cuidar.

Motor 2.5D por proyección oblicua, sin dependencias: HTML, CSS y JavaScript puro.
Se abre `index.html` en cualquier navegador y corre. Se publica subiendo la carpeta
a cualquier hosting estático.

- `index.html` — la página
- `src/` — el motor
- `docs/DISENO.md` — la tesis del juego, las reglas y el diccionario de glifos

Empezar a leer por `docs/DISENO.md`.
